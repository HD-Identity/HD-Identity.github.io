本指南使用 `mack-a` 八合一脚本，通过 **一键无域名 Reality** 选项，快速部署 VLESS+Reality 协议，无需购买域名或配置证书。

## 1. 准备工作

- 一台海外 VPS（Ubuntu 20.04+ / Debian 10+）
- 服务器的公网 IP
- 根权限（root 用户，或 sudo 权限）
- SSH 客户端（Windows 可用 PowerShell 或 Xshell）

## 2. 连接服务器

假设你的密钥文件为 `server.pem`，公网 IP 为 `1.2.3.4`：

```bash
# 修改密钥权限（仅限 Windows）
icacls "C:\path\to\server.pem" /reset
icacls "C:\path\to\server.pem" /inheritance:r
icacls "C:\path\to\server.pem" /grant:r "%USERNAME%:(R)"

# SSH 登录（默认用户名 ubuntu/root/ec2-user，根据镜像选择）
ssh -i "C:\path\to\server.pem" ubuntu@1.2.3.4
```

## 3. 一键安装 VLESS+Reality

### 3.1 下载并运行脚本

```bash
wget -P /root -N --no-check-certificate "https://raw.githubusercontent.com/mack-a/v2ray-agent/master/install.sh" && chmod 700 /root/install.sh && /root/install.sh
```

### 3.2 脚本菜单操作

1. 出现主菜单后，输入 **`3`**（一键无域名 Reality）
2. 选择核心：输入 **`1`**（Xray-core）
3. 等待自动安装，过程中可能会询问：
   - `是否更新、升级？[y/n]` → 输入 `y`
   - `请输入自定义UUID[需合法]，[回车]随机UUID` → 直接 **回车**
   - `请输入自定义用户名` → 直接 **回车**
   - `请输入端口[回车随机10000-30000]` → 直接 **回车**（或手动指定如 `443`）
   - `请输入目标域名，[回车]随机域名` → 直接 **回车**
   - `请输入 Private Key[回车自动生成]` → 直接 **回车**

脚本完成后会自动生成节点信息，**请务必保存输出的 `vless://` 链接**。

## 4. 开放防火墙端口

### 4.1 云安全组（必须）
在 VPS 控制台添加入站规则：
- **协议**：TCP
- **端口**：你设置的端口（例如 `16357` 或 `443`）
- **来源**：`0.0.0.0/0`

### 4.2 服务器内部防火墙（可选）

```bash
# 如果使用 ufw
sudo ufw allow 16357/tcp
sudo ufw reload

# 如果使用 firewalld
sudo firewall-cmd --add-port=16357/tcp --permanent
sudo firewall-cmd --reload
```

## 5. 性能优化：开启 BBR

```bash
echo "net.core.default_qdisc=fq" | sudo tee -a /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# 验证
sysctl net.ipv4.tcp_congestion_control
# 输出应为 bbr
```

## 6. 获取节点信息

### 6.1 查看所有账号

```bash
vasma
# 选择 7 → 1（查看账号）
```

脚本会输出：
- **vless 链接**（直接导入客户端）
- **通用订阅地址**（用于 v2rayN 订阅）
- **clashMeta 订阅地址**（用于 Clash Verge Rev）

### 6.2 保存关键信息

复制 `vless://` 开头的链接，例如：

```

```

## 7. 客户端配置

### 7.1 使用 v2rayN（Windows 推荐）

1. 下载 [v2rayN](https://github.com/2dust/v2rayN/releases)（带 `-with-core` 的版本）
2. 解压后运行 `v2rayN.exe`
3. **直接复制 vless 链接**，在软件主界面按 `Ctrl+V` 导入
4. 右键节点 → **设为活动服务器**
5. 右键托盘图标 → **系统代理** → **自动配置系统代理**

验证：浏览器访问 `http://ip.sb`，显示你的服务器 IP 即成功。

### 7.2 使用 Clash Verge Rev（跨平台）

1. 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)
2. 运行后进入 **订阅** 页面
3. 点击 **添加订阅**
   - 名称：随意
   - URL：粘贴脚本输出的 **clashMeta 订阅地址**（例如 `http://38.244.47.185:30806/s/clashMetaProfiles/xxx`）
4. 点击 **确定** → **更新**
5. 在 **代理** 页面选择节点，开启 **系统代理** 或 **TUN 模式**

## 8. 常见问题

### 8.1 导入订阅失败：invalid yaml

- **原因**：v2rayN 使用了 clashMeta 订阅地址
- **解决**：v2rayN 应使用 **通用订阅**（`/s/default/xxx`），而非 clashMeta 订阅

### 8.2 连接成功但无法上网

- 检查系统时间是否准确（误差 >1 分钟会导致 Reality 握手失败）
- 检查服务器端口是否被防火墙阻断：`telnet 服务器IP 端口`
- 尝试更换 `sni` 参数（如改为 `www.microsoft.com`）

### 8.3 重启服务器后代理失效

```bash
systemctl status xray    # 查看状态
systemctl enable xray    # 确保开机自启
systemctl restart xray   # 手动重启
```

